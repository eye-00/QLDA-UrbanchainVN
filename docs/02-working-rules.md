# Working Rules for Codex and AI Agents

## Bat buoc
1. Luon doc backlog ID truoc khi code
2. Khong tu y doi nghiep vu dat dai
3. Khong luu PII nhay cam tren blockchain
4. Khong doi API contract neu chua cap nhat `docs/07-api-contract.md`
5. Khong doi event/ABI neu chua cap nhat `docs/06-smart-contract-spec.md`
6. Moi patch phai co test hoac ly do vi sao chua co test
7. Neu co mau thuan giua code va docs, uu tien docs va danh dau `NEEDS_PM_DECISION`

## Quy trinh lam viec
- Plan truoc
- Lam thay doi nho
- Bao cao assumptions ro rang
- Tu kiem tra build/test truoc khi de xuat merge

## On-chain rules
- Chi luu hash/CID, tx hash, on-chain identifiers
- Khong luu CCCD, ho ten day du, dia chi chi tiet, file scan tren chain

## Phap ly va nghiep vu
- Ho so lan dau va bien dong phai ton trong luong nghiep vu co quan nha nuoc
- AI OCR chi la cong cu ho tro
- Trang thai ho so phai thong nhat giua UI, API, DB va contract mapping

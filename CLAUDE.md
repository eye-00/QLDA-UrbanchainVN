# UrbanChain-VN Working Constitution

## Project focus
UrbanChain-VN is an MVP for land-registration workflows. Off-chain workflow is the source of truth. Blockchain only records minimal immutable references.

## Must-follow constraints
- Do not store personal data on-chain.
- Follow `docs/05-workflow-land-law.md` for workflow.
- Follow `docs/06-smart-contract-spec.md` for contract.
- Follow `docs/07-api-contract.md` for API.
- Every code change must map to backlog IDs and include tests.

## Preferred execution order
1. Plan
2. Update spec if needed
3. Implement minimal patch
4. Add/adjust tests
5. Summarize assumptions and risks
